# Lead Notification System

## Overview
This automation sends instant notifications when a new lead is captured from a form or webhook.

---

## Problem
Businesses often lose leads because they don’t get notified instantly when a user submits a form.

---

## Solution
This n8n workflow captures lead data and sends instant notifications to WhatsApp, Telegram, or Email.

---

## Tools Used
- n8n
- Webhook Trigger
- WhatsApp API / Telegram Bot / Email Node

---

## Workflow Steps
1. Lead submits form
2. Webhook captures data
3. n8n processes the information
4. Notification is sent instantly

---

## Output
Instant alert containing lead details.
