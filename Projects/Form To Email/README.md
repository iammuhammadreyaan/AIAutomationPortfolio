# Form To Email Automation

## Overview
This automation sends form submissions directly to email using n8n.

---

## Problem
Manually checking form responses takes time and can cause delays in replying to users or customers.

---

## Solution
This n8n workflow automatically captures form submissions and sends the data directly to an email inbox instantly.

---

## Tools Used
- n8n
- Webhook Trigger
- Email Node (SMTP/Gmail)

---

## Workflow Steps
1. User submits a form
2. Webhook receives the data
3. n8n processes the input
4. Email node sends the data to the inbox

---

## Output
Instant email notification containing form data.
